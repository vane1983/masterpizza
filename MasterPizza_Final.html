Configurar sincronización

Seguí estos pasos para que todos los teléfonos compartan los mismos datos en tiempo real

1
Entrá a console.firebase.google.com con una cuenta de Gmail (la de MasterPizza o cualquier Gmail)
2
Hacé clic en "Crear un proyecto" → nombre: masterpizza-tandil → seguir sin Analytics → Crear proyecto
3
En el menú izquierdo → Compilación → Realtime Database → "Crear base de datos" → elegí Sudamérica → Iniciar en modo de prueba → Habilitar
4
Volvé al inicio del proyecto → ícono </> (Web) → registrá la app con el nombre masterpizza → NO marques Firebase Hosting → clic en Registrar app
5
Vas a ver un bloque de código con firebaseConfig = { ... }. Copiá los valores y pegálos acá abajo 👇
API Key
Database URL
Project ID
App ID

Si ya configuraste antes, la app carga automáticamente tu configuración.
